# BiliShu · B站飞书皮肤

把 B 站伪装成飞书的油猴脚本。

## 效果展示

### 首页推荐流 → 飞书群聊消息

首页推荐流变成飞书群聊消息，点开卡片就能直接看视频。

![首页推荐流](1.gif)

### 不同分区 → 不同的飞书群

![分区](2.gif)

### 评论区 → 飞书消息

评论区也改成了飞书消息，可以直接在伪装的飞书皮肤内回复。

![评论区](3.gif)

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 等用户脚本管理器
2. 点击安装脚本：[bilishu.user.js](https://github.com/Jack-Cherish/BiliShu/raw/main/bilishu.user.js)
3. 打开 [bilibili.com](https://www.bilibili.com/) 即可
